## Exact production and the named bottleneck

For three distinct registers define `A: i += a*j`, `B: j += b*k`, where nonzero `a,b` are the original dyadic coefficients. These are execution-order identities:

```
A ; B  =  B ; A ; (i += -a*b*k)
B ; A  =  A ; B ; (i += +a*b*k)
```

The correction is essential. Apply the gates sequentially to symbolic input rows to check both equalities; also apply each inverse-transpose gate in the same chronological order for the dual identity. The correction commutes with A and B, but this family fixes it at the end and does not expand the domain to other placements after observing results.

The cost-bearing bottleneck is a middle register `j` that must leave the pair at a smaller frame than the eventual frames of `i` and `k`. In the AB orientation, choose nested spaces `R < S < T`, entries `(E_i,E_j,E_k)=(S,R,R)` and exits `(O_i,O_j,O_k)=(T,S,T)`. The old adjacent pair is forced to use frame S twice. `H_(x+y) - H_x - H_y < 0` for positive x,y and `H_r=(r/73)^(1-C)`, `0<C<1`.

This is strict subadditivity of the concave power, with exactly the same rank mass. It charges the added correction and the climbs into the first unchanged exterior touches.
