## A necessary cost-bearing distinction

There is a source-level obstruction to naive uncontracted conjugation.
If every original contact is kept and only correction/encoding contacts are
added, projecting a new feasible frame labeling onto the original contacts
is feasible for the original graph. Deleting an added contact merges rank
jumps `a,b`; concavity gives `f(a+b) ≤ f(a)+f(b)` for
`f(r)=(r/73)^(1-k)`. The original complete paid bill is therefore no larger.
Uncontracted conjugation alone cannot improve a true old-graph optimum.
This observation was sent to the coordinator before any execution or source
freeze. It is a proof about graph refinement, not a measured candidate null.

Consequently scalar cancellation is the part that could make this basis
change cost-bearing: a conjugated read correction can cancel another read,
removing an old contact from the encoded graph. R2 fixes the correction
BEFORE the original consumer read. It then uses a stack to coalesce adjacent
same-directed adds by exact coefficient addition, deleting zero sums.
The B and restore portions are reduced separately, and every warp is a
barrier. There is no commuting exposure or cross-section reduction. Every
original/correction origin and coalescence/deletion is retained in the trace.
This constructor is fixed in the R2 preregistration, before any execution.

The named source motif at restore190–191 is
`59 -=73; 59 -=363`. Under `363 +=73`, the second read becomes
`59 +=73; 59 -=363`. The first two adjacent73 reads cancel, so an original
contact disappears. The complete encode, remaining B/restore operations and
decode still have to be charged. This establishes only a changed graph;
it does not establish that a feasible complete word is cheaper.

For example, the rank-one four-register operator

`x += a*u; x += b*v; y += c*u; y += d*v`, with `a*d=b*c`,

can be encoded by `u += (b/a)*v`, followed by two reads of the encoded `u`,
and decoded afterward. The opposite `v` read terms cancel exactly. The
temporary dirty register is restored, so no extra buffer is free. This is a
generic proof of possibility, not evidence that the named source intervals
contain that rectangle. It is also not a priority claim over the recorded
small-wire/shared-form literature or the original elementary-basis identities.
